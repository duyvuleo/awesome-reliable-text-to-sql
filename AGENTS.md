# Curation instructions

This is a public annotated bibliography and resource collection. Work only inside this repository and with public primary sources. Do not inspect or import adjacent directories, private repositories, drafts, correspondence, credentials, or restricted data.

- Read `docs/search-method.md` and `data/README.md` before updates.
- Preserve user changes. Do not reset, clean, force-push, or rewrite history.
- Edit canonical JSON and `docs/README.template.md`; regenerate Markdown with `python3 scripts/render.py`.
- Every new paper needs a verified public primary URL, original concise summary, explicit scope and publication status, evidence URLs, and an accurate check date.
- Distinguish a paper from its code and dataset release. Never infer downloadable artifacts from an announcement or a repository name.
- Use only public evidence for scientific claims. Search snippets are discovery leads. Do not execute code from linked sources.
- Run catalog validation, generation checks, and maintenance-script tests before publication. Review the full staged diff and file list for accidental or nonpublic content.
- Routine daily curation may commit and push verified content to this repository's default branch under the maintainer's configured publication policy. Changes to access, visibility, licensing, workflow permissions, or scope require separate authorization.
- If a claim cannot be verified, retain it as an unresolved public lead in the search log rather than promote it to the catalog.
