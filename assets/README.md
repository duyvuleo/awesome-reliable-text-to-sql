# Visual assets

The banner and social-preview artwork is original to this collection and covered by the repository's CC0 dedication.

| Asset | Use |
| --- | --- |
| [banner-light.svg](banner-light.svg) | README banner on light backgrounds, 1280 × 360. |
| [banner-dark.svg](banner-dark.svg) | README banner on dark backgrounds, 1280 × 360. |
| [social-preview.svg](social-preview.svg) | Editable social-card source, 1280 × 640. |
| [social-preview.png](social-preview.png) | Social-card export for GitHub and sharing, 1280 × 640. |

Run `python3 scripts/build_visuals.py` to regenerate the SVG sources. Export `social-preview.svg` as a 1280 × 640 PNG after changing the artwork. The PNG should stay below 1 MB for GitHub's social-preview setting. The graphic contains no changing paper counts or performance claims.
