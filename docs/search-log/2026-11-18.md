[DecoVal](https://arxiv.org/abs/2611.20511) was found through the supplementary SQL-verification query and read through all 20 pages, proofs and appendices. The [note](../../papers/notes/decoval.md) separates exact search over a modeled decomposition space from actual semantic correctness. Its probability interpretation requires independent task errors and accurate local reliability estimates; LLM-generated requirements can still be wrong. Human error-detection results are 10/11 versus 4/11 judgments over two prepared tasks, with longer median validation time on incorrect queries. LLM recall improvements must be read alongside false rejections and execution-based labels.

One [DecoVal tool entry](https://github.com/Inverse0/validation-aware-decomposition/tree/a1aacc8b554749768544025fbafb569543c0562d) records public source and benchmark listings.
