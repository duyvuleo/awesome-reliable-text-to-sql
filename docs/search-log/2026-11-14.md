## Full-paper additions and evaluation boundaries

[FlinkEval](https://arxiv.org/abs/2611.17093), submitted 12 November, was read in full through all 17 PDF pages and Appendices A–E. Its Question Specification Ladder is directly relevant to underspecification: oracle clues are supplied offline, and the reported outcomes are model-judge acceptance rather than execution-equivalence accuracy. The [note](../../papers/notes/flinkeval.md) records unvalidated item-level ambiguity, deployment-specific exclusions and the background-statement validation exceptions to the introduction's broad execution claim. The benchmark matrix labels this as static, supplied-clue evaluation without an unanswerability task.

The paper describes corpus versions and file schemas but provides no verified public release URL. Exact-name GitHub and Hugging Face searches did not establish a release. One clearly labeled paper-described benchmark record was added; no downloadable artifact or applicable dataset license is inferred.


[MTSQL-R1](https://aclanthology.org/2026.acl-long.1563/) was followed as an older conversational-verification lead. The complete 34-page proceedings paper, appendices and figures were read. Its memory and execution checks are relevant supporting mechanisms, but the main scores use gold previous SQL; predicted-history performance is a separate CoSQL experiment. It does not evaluate clarification or refusal. The [reading note](../../papers/notes/mtsql-r1.md) also distinguishes reference-based rewards from confirmation of intended semantics.

The official implementation and four public checkpoint listings were checked without execution or weight downloads. At [the inspected revision](https://github.com/taichengguo/MTSQL-R1/tree/a720f970c4308980812d830bd60f1d69f2ab57fa), the released EM scorer parses SQL structurally despite the paper's string-equality definition. The process reward also reads execution-verdict tags for the memory action, whose prompt requests a different tag. These are static-source reproducibility caveats; their impact on published runs was not established. Repository and 4B model licenses are documented separately from the unverified 1.7B model terms.

[STRATOS v2](https://arxiv.org/abs/2607.03501) was discovered through the recent-update scan and read in full: 13 PDF pages, all figures and tables. It is adjacent work on domain/spatial grounding, with a useful error analysis of valid aggregation alternatives rejected by one reference. The [note](../../papers/notes/stratos.md) keeps automatic grounding distinct from clarification, paired exact/approximate spatial definitions distinct from equivalent SQL, and EXPLAIN checks distinct from semantic verification. An official implementation or workload release was not established. The broad spatial workload was not added as a dedicated ambiguity/answerability benchmark.
