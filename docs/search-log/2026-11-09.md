## Verified additions

- [Speak to your Parser / SPLASH](https://aclanthology.org/2020.acl-main.187/): verified ACL 2020 publication and inspected the [task, construction and evaluation sections](https://aclanthology.org/2020.acl-main.187.pdf), especially Sections 3, 5 and 6. The paper explicitly separates correcting fully specified questions from asking about ambiguity. Its supplied feedback and exact-set-match evaluation are recorded as an adjacent benchmark, not a refusal or live clarification benchmark.
- [NL-EDIT](https://aclanthology.org/2021.naacl-main.444/): verified NAACL 2021 publication and inspected [Sections 4–7](https://aclanthology.org/2021.naacl-main.444.pdf), covering contextual edit prediction, synthetic feedback, irrelevant edits and cross-parser generalization. This is a distinct correction method building on SPLASH; its reuse of the original corpus was not counted as a duplicate dataset.
- [BAR-SQL](https://arxiv.org/abs/2601.10318): verified the January 2026 preprint and inspected [Sections 2.2–2.3, 3.3 and 4.1](https://arxiv.org/html/2601.10318v1). Ent-SQL-Bench includes clarification, required-constraint and rejection targets. SQL outputs use execution matching, while natural-language responses use LLM judgments. The catalog does not turn these response-level scores into evidence of completed clarification dialogues or cross-domain reliability. No independent proceedings publication was established.

## Artifacts and benchmark distinctions

The [SPLASH repository](https://github.com/MSR-LIT/Splash) lists four JSON files in its data directory and explicitly declares CC BY-SA 4.0. It documents Spider database IDs and evaluation that ignores SQL values. The files were not downloaded; database dependencies and model baselines were not run.

The [NL-EDIT repository](https://github.com/MSR-LIT/NLEdit) contains SQL edit/explanation utilities, synthesis scripts, SPLASH-derived files and parser-specific correction annotations. Its README still uses forthcoming-release wording, but the file inventory is populated. The catalog therefore describes the visible utilities without claiming a complete neural-model release. No LICENSE was listed and no reuse terms were inferred. The paper's additional cross-parser sets remain accessible through the paper's dataset link; this pass does not add a second copy of SPLASH to the dataset count.

The [BAR-SQL repository](https://github.com/TianSongS/BAR-SQL) contains synthesis, SFT/GRPO and evaluation scripts. Its [benchmark directory](https://github.com/TianSongS/BAR-SQL/tree/main/benchmark) lists Ent-SQL-Bench.json. The paper describes 1,262 held-out instances; file contents, model-weight availability and the database environment were not independently validated. The README declares MIT and links a LICENSE file that was absent from the checked tree. Dataset-specific terms remain unverified. Ent-SQL-Bench is distinct from the already cataloged EntSQL long-context enterprise-knowledge benchmark.
