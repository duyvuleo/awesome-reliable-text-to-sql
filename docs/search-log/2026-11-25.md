## Added after complete reading

[Know When to Abstain](https://arxiv.org/abs/2611.31190) was read through all 32 pages and Appendices A–H, with all six figures inspected. The [note](../../papers/notes/conformal-confidence-abstention.md) distinguishes the correct-class conformal p-value's marginal false-abstention bound from the separate Learn-then-Test selective-risk rule. Both rely on their sampling assumptions and execution-match labels. Tight budgets can yield zero accepted queries; the Spider-certified threshold exceeds its risk target on BIRD transfer. Code is promised upon acceptance, but no official artifact release was verified or counted.

[Semantic-aware Decoding](https://arxiv.org/abs/2611.30873) was read through all eight pages, Algorithm 1, figures and tables. The [note](../../papers/notes/semantic-aware-decoding.md) explains that SLA protects the local top token within the allowed set after masking, not the original complete SQL output or semantic validity. Evaluation uses selected AmbiQT categories and 373 AMBROSIA vagueness cases with some third references removed. Top-five coverage, candidate precision, selected answers and successful dialogue are distinct outcomes. Comparison exceptions and mixed baseline models remain explicit. No author-linked implementation was verified; reused benchmark subsets were not newly counted.

[Mind the Trap](https://arxiv.org/abs/2611.29009) was read through all 17 pages and Appendices A–E, with all 14 figures checked. The [note](../../papers/notes/mind-the-trap.md) distinguishes repeated rows from incorrect intended grain, and targeted fan-out error reduction from general SQL accuracy. Labels are model-produced; reference-query table exposure, outcome-selected development cases, post-run review and in-sample synthetic tasks constrain inference. Correct intended-repetition answers can trigger the audit, so its flag names are not semantic correctness certificates.

The [pinned misqal release](https://github.com/ahmed-mahran/misqal/tree/422891572d0d548f8d515444a701d8c18d7352a4) supports one tool and two separately described benchmark entries: BIRD-FanOut's reviewed real-data subsets and GrainTraps's synthetic diagnostic questions/generator. Their documentation and file inventories were inspected without downloading annotation/database payloads or running code. Apache-2.0 source and the stated CC BY-SA 4.0 BIRD-derived materials are distinguished; a separate GrainTraps data license was not verified. GrainTraps's ambiguity label refers narrowly to its 27 vague twins, not exhaustive user-intent coverage or a clarification task.

The six-page [LTRC-IIITH EHRSQL 2024 paper](https://aclanthology.org/2024.clinicalnlp-1.66/) was read completely, including both figures and the threshold table. The [note](../../papers/notes/ltrc-iiith-ehrsql-2024.md) separates intrinsic answerability classification from rejection of low-confidence or execution-failing candidates. Its threshold uses the distribution of test prediction scores, which is not independent calibration and does not establish test-label training. The reported submission threshold is not best for every utility penalty. The [pinned MIT implementation](https://github.com/jr-john/ehrsql-2024/tree/4935c2d0f1c2abc4e05d57ad91c2ab2e3f0cbd4b) was added as a system; static inspection shows batch generation/execution before final abstention and no rejection solely for an empty result. No EHRSQL dataset duplicate or clinical deployment claim was added.
