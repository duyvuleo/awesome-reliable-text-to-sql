## Added after full-paper reading

[Calibrated Interpretation: Confidence Estimation in Semantic Parsing](https://aclanthology.org/2023.tacl-1.69/) fills a historical calibration gap identified by citation following. All 19 journal pages were read, including the SQL and dialogue experiments, metrics, difficulty analyses, challenge splits and limitations. The [2022 preprint](https://arxiv.org/abs/2211.07443v6) and 2023 journal article are one work.

The [detailed note](../../papers/notes/calibrated-interpretation.md) preserves distinctions that matter for reuse: teacher-forced token diagnostics versus generated-program confidence; principal exact-match labels versus the separate T5-base Spider test-suite analysis; and SQL experiments versus dialogue-only CodeGen and EASY/HARD split results. The work measures calibration and does not validate a live clarification or abstention policy. It is marked adjacent.

## Verified tool and artifact limits

The paper links both the [analysis repository](https://github.com/esteng/calibration_miso) and [calibration metric library](https://github.com/esteng/calibration_metric). The former exposes SQL experiment links and a verified MIT license. The latter provides metric, plotting and reader source with fixed/adaptive binning; one tool entry records this reusable calibration functionality.

The metric library consumes externally supplied correctness labels, so it does not establish SQL semantics. At [the inspected revision](https://github.com/esteng/calibration_metric/tree/591f55b42820c73c3503a0de0afcf1f7b3b8e1df), its README examples reverse the probability/label argument order shown by the source signature. Its package metadata declares MIT and references LICENSE, but that file was absent from the inspected tree and its direct path returned 404. The catalog preserves this licensing-verification limit rather than inheriting the separate analysis repository's terms. Neither package was installed or executed, and model archives were not downloaded.

No dataset or benchmark comparison was added: the new challenge subsets belong to SMCalFlow and TreeDST, while the SQL experiments reuse Spider and CoSQL.

## Screened or held outside the main catalog

- [Did You Mean...? Confidence-based Trade-offs in Semantic Parsing](https://aclanthology.org/2023.emnlp-main.159/) was screened through the full extracted article and appendices. Its oracle-assistance and real-user gloss-confirmation studies use SMCalFlow Lisp-like programs; no SQL-specific validation is reported. The exclusion is about collection scope, not an absence of human evidence. SQL transfer remains a possible method connection rather than an established result.
- [Text-to-SQL Clarify](https://github.com/fadil013/text-to-sql-clarify) is a real MIT-licensed PostgreSQL prototype with clarification, guard and repair code. Inspection at [revision 7767d60](https://github.com/fadil013/text-to-sql-clarify/commit/7767d60f882f8429ac0122f1b5e9f31749082142) found a small reused tuning set and no recorded end-to-end clarification ablation. Its ablation runner checks question/type behavior and completion after choosing the first option, without an intended-answer reference for ambiguous cases. It remains a public lead pending stronger clarification-outcome evidence; no project code was executed or security guarantee established.
- [FERN](https://arxiv.org/abs/2611.14477) was screened at the primary record and its task, discussion and limitation sections. It measures table retrieval, explicitly excluding downstream SQL generation. [NIFT-SQL](https://arxiv.org/abs/2611.12731) remains under the preceding retrieval-only scope decision. Neither screening established a dedicated ambiguity, answerability, clarification or abstention evaluation warranting catalog expansion; these were not complete full-paper audits.
