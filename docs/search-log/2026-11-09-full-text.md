# 2026-11-09 — Full-paper audit of the existing collection

This audit revisited all **94 cataloged papers**. It completed **91 version-specific full-paper readings** and recorded **3 full-text access gaps**. It added no new papers and is not a new claim of exhaustive literature-search coverage.

The [reading index](../../papers/reading-notes.md) links each paper's methods, evaluation conditions, findings, limitations and located checks. The canonical [reading records](../../data/paper-reviews.json) identify the public version, substantive material read and separately inspected supplements. Full reading does not establish independent reproduction; no linked research code was executed.

## Material revisions

- Separated interpretation coverage from selecting a user's intended interpretation, and supplied dialogue from an agent choosing questions. Examples include [CLARITY](https://aclanthology.org/2026.acl-industry.86.pdf), [CoSQL](https://aclanthology.org/D19-1204.pdf), [AMBROSIA](https://arxiv.org/pdf/2406.19073v2) and [BIRD-Interact](https://arxiv.org/pdf/2510.05318v3).
- Qualified reliability claims by their actual loss, answered subset, feedback assumptions and label oracle. Examples include [RTS++](https://openproceedings.org/2026/conf/edbt/paper-177.pdf) and [Certified Against Which Oracle?](https://arxiv.org/pdf/2609.25938v1).
- Added human-study evidence with its real scope, including [DialSQL](https://aclanthology.org/P18-1124.pdf), [Sphinteract](https://www.vldb.org/pvldb/vol18/p1145-zhao.pdf) and the [clinical conversational-interface study](https://arxiv.org/pdf/2611.00605v1). Gold-visible conditions, partial-credit outcomes and post-study adjudication remain explicit where applicable.
- Corrected healthcare benchmark interpretation: [EHRSQL](https://arxiv.org/pdf/2301.07695v6) includes some ambiguity within its unanswerable category; [Text-to-OMOP](https://aclanthology.org/2026.clinicalnlp-1.40.pdf) mixes seen and held-out SQL variations; [SCARE](https://raw.githubusercontent.com/mlresearch/v297/main/assets/lee26b/lee26b.pdf) supplies execution evidence to several baselines.
- Verified additional official artifact links for [Query Carefully](https://github.com/JasminSaxer/QueryCarefully), [semantic path compilation](https://github.com/yai333/Semantic-Planning-and-Deterministic-for-Text-to-SQL), [oracle-abstention analysis](https://github.com/yahiko-l/text-to-sql-oracle-certificates), [RAQS-SQL](https://github.com/pminhtam/RAQS-SQL) and [EntSQL](https://huggingface.co/datasets/XuWave/Rethinking_Enterprise_Text_to_SQL). Availability descriptions distinguish visible source/data from runnable packages, withheld labels and reproduced results.
- Reconciled bibliographic and release descriptions against inspected versions. Apparent numerical or protocol conflicts are retained with exact locations and cautious assessments; they are not evidence of misconduct or proof that an implementation ran incorrectly.
